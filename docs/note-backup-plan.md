# 备忘录备份功能 · 定稿方案

状态：已实施，模拟器全流程验证通过（2026-10-30，见文末验证记录）
日期：2026-10-30

## 1. 背景与目标

小米换机后出现"主密码错误"：主密码校验本身不绑定设备（只依赖库内 `note_meta` 的
salt/check + 用户密码），报错说明整机迁移时 SQLite 数据回退/不完整，库里的 salt/check
与用户当前密码不是同一时代；指纹路更依赖 Android Keystore 硬件密钥，物理上不可跨设备
迁移。结论：**凡是绑定设备/绑定主密码/绑定应用数据的机制，在换机、丢机、数据损坏、
忘记密码时都可能失效**。

本功能的目标是建一条独立于这台手机、独立于主密码、甚至独立于本应用的数据逃生通道：

- 数据以**通用格式**（标准 ZIP + 明文 JSON）存在**用户自己控制的地方**（U盘/SD卡/
  云盘同步目录/电脑）；
- app 平时只负责**督促**备份（提醒关不掉直到备份过），执行永远在用户手上；
- 恢复**只往里加、绝不动现有数据**，最坏结果只是多出重复条目；
- 一切状态可推导（计数实时算），无后台自动行为。

## 2. 设计原则（讨论确认的意图）

1. 备份内容含明文（由此才能不依赖主密码恢复），文件唯一保护是可选的 ZIP 密码。
2. ZIP 为标准格式，任何解压软件（WinRAR/7-Zip/系统自带）可打开。
3. 恢复 = 纯导入追加，不替换、不合并、不去重、不碰主密码/指纹（空库首次设置除外）。
4. 提醒是督促：数据变动后常驻，用户备份过才可手动关闭；不做置灰，点击后 Toast 提示。
5. 不做自动备份、不做轮转删旧、不做密码存储、不做模式开关。

## 3. 备份文件规格

| 项 | 定稿 |
|---|---|
| 容器 | 标准 ZIP；填密码 = AES-256 加密（zip4j，WinRAR/7-Zip 输同一密码可解）；留空 = 无密码明文 ZIP |
| 内容 | 单个 JSON 文件：`{ format, exportedAt, entries: [...] }`，entries 内全部字段（含 secret 字段）为**明文** |
| 密码 | 备份时弹窗现场输入，**可留空**；app 不存储；忘记 = 该备份永远打不开（弹窗内提示） |
| 命名 | `备忘录备份_yyyyMMdd_HHmm.zip`，同名冲突时追加秒或序号 |
| 去处 | 用户选定的 SAF 目录（`OpenDocumentTree` + persistable 授权），U盘/SD卡/云盘同步目录均可 |
| 轮转 | **无**。每次备份都是新文件，旧文件不删 |

风险明示（已在 UI 提示）：留空密码的备份含全部密码/2FA 密钥明文，目录安全由用户负责。

## 4. 本机持久化数据（均在应用私有目录，不进数据库）

| 数据 | 形式 | 用途 |
|---|---|---|
| 备份目录 tree uri | SharedPreferences 一条字符串 | 备份写入目标 |
| 底版指纹表 | 私有目录小文件：`{ 条目id: SHA-256(该条目序列化含密文与ord) }` | 计算 X 的基准 |
| 变动时间戳 lastChangeAt | SharedPreferences | 最近一次数据变动时刻 |
| 备份记录列表 | SharedPreferences JSON：`[{time, fileName}]` | 弹窗展示 + 现算 N |

底版指纹对**密文**计算，无需解锁；不含明文，不可逆。改主密码会使全部指纹变化 →
X = 全部条数（语义正确：改密后确实该重新备份）。

## 5. 变动数 X（实时计算，不存计数）

```
X = |当前每条目指纹 与 底版指纹表 的差集|
  = 新增条数 + 删除条数 + 内容/排序变化条数
```

- 每次需要显示时现场计算（readPlain → 逐条 SHA-256 → 与底版比对）。
- 从未备份过且库非空：X = 全部条数。

## 6. 备份次数 N（实时计算，不存数字）

```
N = 备份记录中 time > lastChangeAt 的条数
```

- 数据变动（保存条目/修改主密码/导入数据完成）时更新 lastChangeAt → N 自然归零。
- 每次备份成功：记录追加 → N 自然 +1。

## 7. 提醒机制

- **出现**：X > 0 时，备忘录模块**所有页面**（列表/编辑/设置）底部显示提醒条
  （红色 error 底 + 白字 + ⚠，醒目提示）
  "X 条变动未备份"。
- **常驻**：提醒条不自动消失，备份完成后仍在。
- **关闭**：仅通过提醒弹窗的 [关闭提醒]，永远可点（不置灰）：
  - N > 0 → 关闭提醒条，本次隐藏（内存标志，不落盘）；
  - N = 0 → Toast"本次变动后还没有备份过"，不关闭。
- **重现**：被关闭后，下次 X>0（新变动）时重新出现。

## 8. 弹窗规格

### 8.1 提醒弹窗（点击提醒条打开）

```
┌─ 备份提醒 ──────────────┐
│ 待备份变动：X 条           │
│ 本次变动后已备份：N 次      │
│ ZIP密码(可留空=不加密) [  ] │
│ ─ 备份记录 ─              │
│  10-30 12:01 备忘录备份_xxx.zip │（可滚动）
│ [立即备份]  [关闭提醒]      │
└──────────────────────────┘
```

- 备份成功 → 成功态：`✓ 已备份到 <目录>` + 文件名 + [分享] + [关闭提醒]（此时 N≥1）。
- [分享] 点击才唤起系统分享面板（复用现有导出分享），可直接返回不分享。

### 8.2 设置·备份弹窗（设置页"立即备份"打开）

- 与提醒逻辑完全无关：只有 ZIP 密码框（可留空）+ [备份]。
- 成功态：`✓ 已备份` + [分享] + [完成]。
- **不显示 X、N、备份记录、关闭提醒**。

## 9. 备份执行流程（两个弹窗同一条路）

```
点[备份/立即备份]
→ 未配置目录：先弹系统目录选择（选完接着走）
→ 验证身份：已启用指纹走 BiometricPrompt，否则输主密码（复用现有查看密码的验证）
→ 全量解密 readSecrets(DK)
→ 打包明文 JSON → ZIP（按是否填密码决定加密）
→ 写入 SAF 目录（写入失败 Toast 提示，不改任何状态）
→ 成功：刷新底版指纹、备份记录追加、成功态展示
```

## 10. 恢复（纯导入）

```
设置页[恢复备份]
→ 系统文件选择器选 zip
→ 加密的输 ZIP 密码（错则 Toast 重试；无密码直接读）
→ 确认弹窗"备份时间 / N 条"
→ 验证身份拿当前 DK（库未设主密码 → 先引导设置，即换机空库场景）
→ 备份内 N 条全部追加到列表末尾：
    明文字段用当前 DK 加密落库；条目 id 与现有冲突时自动换新 id（必能导入）
→ Toast"已导入 N 条"
```

- 不替换、不合并、不去重、不动现有条目/主密码/指纹。
- 同一备份恢复两次 → 两份重复条目，用户长按自行删除（纯导入的自然结果）。

## 11. 设置页"备份与恢复"区块

| 项 | 行为 |
|---|---|
| 备份目录 | 显示当前目录名/未配置，点击弹系统目录选择 |
| 立即备份 | 打开 8.2 纯备份弹窗 |
| 恢复备份 | 进入 10 恢复流程 |

现有手动"导出"三种模式（备份ZIP/加密MD/明文MD）原样不动。

## 12. 明确不做

自动备份、备份密码存储、轮转删旧、合并/替换式恢复、提醒模式开关、WebDAV/云端直连、
旧格式（密文原样备份ZIP）导入。

### 实施与验证注意点（复用必读）

- **FilePicker 必须在 Activity `onCreate` 里创建**（构造时注册 ActivityResultLauncher，
  组合期间创建会抛 "register while RESUMED" 崩溃）；NoteActivity 已按 CompressActivity
  惯例改为属性初始化，NoteApp 里 `remember { (activity as NoteActivity).filePicker }` 取用。
- **Column 包 NavHost 必须给 `Modifier.weight(1f)`**：否则 NavHost 内 LazyColumn 等
  weight 子项测量塌 0 高度，页面只剩 NavHost 外的提醒条（与悬浮路径条塌 0 宽同类教训）。
- **保存后编辑页白屏是既有行为**（persist 置 editing=null + EditorRoute 无 popBackStack，
  HEAD 版本即如此）：白屏=保存已触发，按返回键回列表。非本次改动引入。
- SAF DocumentsUI 网格视图选文件：点**文件名文字左侧**有效；点卡片中部/右侧（预览按钮区）
  可能无响应。目录选择则是进入目录后点 USE THIS FOLDER→ALLOW。
- 键盘收起用 BACK(4)，ESC(111) 无效；**键盘弹出后布局上移，输入框/按钮必须重新 dump 定位**
  （曾因旧坐标两次输入进同一框导致"密码不一致"）。
- uiautomator dump 输出单行 XML：统计文本出现次数用 `grep -o | wc -l`（`grep -c` 按行计恒为 1）。
- Git Bash 下 adb shell 路径须写 `//sdcard/...`（单斜杠会被转成本地路径）。
- Compose AlertDialog 文本节点（如"复制/显示"链接、对话框按钮）的 bounds 是文字本身，
  点击中心即可；列表卡片内 AnnotatedString 链接需按文字估算 x 位置点击。
