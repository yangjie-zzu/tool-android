# EPUB 渲染引擎 v2:CSS 分栏切分 + 栏提取 + 每页 WebView

> 状态:设计定案(2026-10),待实施。
> 前置讨论:自绘降级清单(2026-10)→ 位图物化方案(被否:页不能是图片)→ 整章滚动方案(被否:平移翻页/章 WebView)→ 本方案(CSS 分栏切分 + 栏提取 + 页 WebView)。

## 1. 背景与动机

现有 EPUB 渲染为自绘管线:提取纯文本投影 → 网格分页(StaticLayout 断行)→ 行模型 → Canvas 自绘。它带来统一投影轴(进度/目录/跳页/TTS)与高性能,代价是排版只能覆盖 CSS 子集,长期背负降级清单:

- 表格格内图片不渲染;嵌套表/超 500 格表格整体占位;
- 浮动无文字环绕(`float:right` 降级右对齐,`float:left` 忽略;仅带尺寸浮动有真环绕);
- 跨文档脚注降级普通文本;CSS 选择器不支持 `#id`/`[attr]`/`:pseudo`;
- 首行缩进仅 em;命名色不全;`larger/smaller` 忽略;data URI 图片忽略;
- 固定宽容器在窄视口设备(CSS 视口 360~432px 随设备漂移)横向溢出被截;
- `@font-face` 文字 FOIT 空白;断行/两端对齐质量受自绘实现限制。

降级逐条修补(装饰表格剥除、封面章去重、自适应收缩、FOIT 探测……)追不上真实书籍的 CSS 形态。根治方向:**排版交给浏览器引擎**。

过程中评估并否决的两个中间方案:

| 方案 | 否决原因 |
|---|---|
| 整章快照位图(每页一张 WebP) | 页是图片:长按选择、矢量清晰度、系统字号缩放、无障碍全部丢失,自建补丁(行几何选区)追不胜追 |
| 整章 HTML 常驻 + 滚动定位(平移翻页) | 章级 WebView 常驻被否;平移翻页被否;选择在 overflow hidden 单栏视口下的交互残缺 |

## 2. 定案架构

**切分(CSS 分栏机制)+ 栏提取(物化)+ 每页一个 WebView(渲染)**,三者解耦:

```
打开书/字号主题变更
  → 逐章(隐藏 WebView, 串行, 用完销毁):
      load 整章 XHTML(拦截器映射 css/字体/图片, 剥书内 <script>)
      → 注入分栏 CSS: column-width=版心宽, column-gap, 栏高=版心高
      → fonts.ready + onload → requestIdleCallback(排版稳定)
      → 分桶: 遍历文本节点, 字符矩形按 x 归属栏号 → 每栏字符级 Range 边界
      → 栏提取: Range.cloneContents + 祖先链重建 → 独立页 xhtml
      → 落盘 paged/ch_NNNN_pNN.xhtml + 页目录(每页首字符章内偏移)
  → 页目录对齐全书字符轴(进度/目录/跳页/TTS 沿用)

阅读(页 WebView 池, 2 实例)
  → 当前页 WebView: load paged/ch_NNNN_pII.xhtml
  → 预载 WebView:   load paged/ch_NNNN_pII+1.xhtml
  → 翻页: 覆盖动画(两帧位图过渡保丝滑) → 角色互换 → 空闲实例预载新目标页
  → 长按选择: WebView 原生(选区/系统菜单)
  → 页眉页脚/菜单/进度/夜间: 现有 Compose 叠加层迁移
```

- **分页由 CSS 分栏(fragmentation)完成**:段落跨栏自然流动、孤行控制等由浏览器处理,**无 DOM 切割、无 JS 二分测量**;
- **每页物化为独立 xhtml 文件**(页 = 恰好一栏内容,页内 `overflow:hidden` 无滚动),页 WebView 只加载自己那一栏的文件——严格满足"一页一 WebView、无章 WebView、分页物化、不平移"。

## 3. 核心组件设计

### 3.1 分桶与栏边界(测量 JS)

- `TreeWalker` 遍历章内文本节点,逐字符(步长采样 + 端点精化)`getBoundingClientRect`,按矩形中心 x 归属栏号;
- 输出:每栏首/末字符位置(文本节点引用 + 偏移)→ Range;顺带记录每栏首字符的**文本累计偏移**(章内 DOM 文本轴,用于进度换算);
- 时机:`fonts.ready + onload` 之后(`requestIdleCallback`),字体未就绪时高度测量全错(FOIT);页内 4s 硬超时兜底。

### 3.2 栏提取器(物化核心)

- `Range.cloneContents()` 提取栏内容:跨栏文本节点自动分割、标签自动平衡;
- **祖先链重建**(关键):Range 的 fragment 不含外层祖先——从栏首节点向上克隆到 body 的**祖先壳**(cloneNode(false) 逐层嵌套),fragment 装回最内层,保证依赖祖先的选择器(如 `.set-box1 p`)、背景/边框语义保真;
- 组装:`原文档 head(样式/字体链接, 相对路径按页文件位置改写) + 祖先壳(内含 fragment)`;
- **页 HTML 不注入分栏 CSS**(否则单页内容再被分栏);自适应 CSS(`img,svg{max-width:100%}`)保留;
- 序列化落盘 `paged/ch_NNNN_pNN.xhtml`,附带页目录 json(每页首字符章内偏移)。

### 3.3 页 WebView 池(渲染)

- 池 2 实例:当前页 + 预载目标页(各加载自己的页文件,经现有 DECOR_HOST 拦截器映射 css/字体/图片);
- 翻页:覆盖动画;动画期间以两 WebView 的**位图帧过渡**(动画帧不直接驱动活 WebView,保证丝滑),落定后角色互换,空闲实例预载新目标页;
- 快速连翻:目标页跳变时以最终页为准,取消中间预载;
- 崩溃运维:`onRenderProcessGone` → 销毁重建、回到当前页;
- 页眉页脚/夜间滤镜:沿用绘制叠加层(页文件不含主题,夜间由 WebView 层 ColorMatrix/注入 CSS 处理)。

### 3.4 进度与功能层对齐

- 页目录记录每页首字符的**章内 DOM 文本偏移**,与投影轴按比例换算(章内近似,进度/跳页精度足够;空白规整处误差 ±数字符);
- 目录/跳页/百分比/TTS:沿用全书字符轴;
- 长按选择:WebView 原生选区(系统菜单),自建 SelectionGeometry 在 EPUB 路径退役;复制文本可由 JS 桥取选中内容;
- 脚注角标点击:JS 桥上报考点 → 现有脚注弹层复用。

### 3.5 生成策略

- 打开书时全量物化页文件 + 页目录(首开约 5-15s,loading "排版中…x/y";Section007 657 段为基准);
- 缓存失效:字号、版式指纹(边距/视口)、渲染器版本(分栏/提取逻辑变更)→ 全量重物化;夜间主题走 CSS 不失效;
- 物化失败的页:错误态 + 重试入口(EPUB 无自绘回退,已拍板);
- 落盘体积:全书约 700 页 × 5-20KB ≈ 10-20MB(cache 目录)。

## 4. 与现有架构的关系

| 组件 | 去留 |
|---|---|
| HtmlTextExtractor(投影/脚注/封面/h2 拆章) | 保留(进度轴/目录/功能层仍依赖) |
| 网格算法(LineGrid/PaginationEngine/BookPager.buildSpecs) | EPUB 路径退役;TXT 保留 |
| 行模型/自绘排版/SelectionGeometry(EPUB 分支) | 退役;TXT 保留 |
| ReaderPageView + 拖拽翻页 + 页眉页脚 + 图片 LRU | 改造为位图/WebView 页宿主 |
| DecorSnapshot/deco_v2/装饰章判定/isDecorativeChapter | 退役(被分栏物化吸收) |
| 装饰表格剥除(dedupeLeadingTitle 表格分支)、封面章去重(coverChapterLingers) | 随降级问题消失,清理 |
| 脚注弹层/菜单/设置/进度/TTS | 保留(部分经 JS 桥) |
| TXT 自绘管线 | 不变(按 format 分派) |

EPUB **无自绘回退**(已拍板):物化失败显示错误态 + 重试。

## 5. 实施分解

1. **PoC(风险最大环节先行)**:真书最长章 Section007(657 段)——分栏排版 + 分桶 + 提取器 + 页文件在池 WebView 中渲染,与分栏原稿并排对比;测:提取耗时/页边界准确性(不重不漏)/祖先链 CSS 保真;
2. 物化服务化:按章串行物化 + 页目录/失效策略 + 阻塞 loading 接入 load 流程;
3. 页 WebView 池与 ReaderScreen 迁移(EPUB 分支):翻页动画、角标桥、选择、夜间;
4. TXT 回归 + EPUB 全书回归(逐章对比浏览器原稿);
5. 清理退役代码(装饰章快照/表格剥除补丁/封面章去重),文档更新。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 祖先链重建的 CSS 语义偏差 | PoC 并排对比;缺失属性逐项补(继承/背景/边框) |
| 绝对定位/旋转元素跨栏归属 | 按锚点 x 归栏;极端情况容错(该元素完整性优先) |
| 首开物化时长(5-15s) | 一次性成本,loading 进度;后续可做按章惰性物化 |
| 活 WebView 内存(2 实例) | PoC 实测;超预算先砍邻页预载 |
| 渲染进程崩溃 | onRenderProcessGone 重建 + 回当前页 |
| 字号变更全书重物化(分钟级) | 后台 + 进度;旧页文件兜底显示至新页就绪 |
