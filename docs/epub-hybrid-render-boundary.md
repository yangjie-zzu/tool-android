# EPUB 混合渲染:自绘边界声明 + 块级 WebView 降级 + 位图选择/图片预览

> 状态:已实施(2026-10)。实施要点见文末「实施记录」。
> 前置:自绘降级清单逐项修补路线(1.5.4~1.5.7)、章首装饰表格剥除(1.5.5)、装饰章快照机制(七期)、
> 整章 WebView 分栏方案(epub-webview-paginated-render.md,已搁置——本方案为其"边界问题"的块级替代解)。

## 1. 背景与动机

自绘投影管线长期背负 CSS 降级清单,逐形态打补丁(装饰表格剥除、封面章去重、FOIT 探测、
自适应收缩……)追不上真实书籍的形态长尾。典型残留问题:

- 章首标题装饰表格(圆圈章号 + 子集字体 + 右侧立绘)被剥除后仅以纯文本章名行代替,
  装饰形态全失(果青1 Section003 实测);
- 嵌套表/超 500 格表格整体占位文本;
- 内嵌 `<svg>` 标签整段跳过;
- 行内级装饰(span 边框/背景)提取即丢。

同时 WebView 已有成熟的离屏渲染基建(装饰章快照:离屏加载原书 XHTML → WebP 落盘 →
整章一页位图呈现),但粒度是"整章",判定是"首段带盒样式"单信号,误判整章位图的代价
(字号/选择/TTS 失效)使判定只能收窄,大量"强装饰意图、弱 CSS 信号"的形态漏在网外。

本方案把 WebView 的使用粒度从**章**降到**块**(单个块级元素子树),以明确的
"自绘能力边界"信号清单驱动降级,正文流保持自绘,边角形态块级保真。

## 2. 目标与原则

- 自绘管线继续承担正文流:性能、长按选择、字号缩放、TTS 不回退;
- 自绘**明确不支持**的形态以**块**为单位降级 WebView 离屏渲染成位图,嵌入行流;
- 降级采用**信号白名单制**:只命中"自绘明确画不了"的信号才降级,默认自绘;
  不设数量/长度类防滥用上限(渲染失败的功能性兜底除外);
- 块位图必须支持长按选择(字符几何映射);书内图片支持点击查看大图
  (WebView 产生的位图除外)。

## 3. 自绘能力边界(正式声明)

### 边界内(继续自绘,永不降级)

段落/标题/列表;行内样式(粗斜下删/上下标/字号 em·px·%·关键词·larger·smaller/
颜色 #·rgb·148 命名色/text-shadow/@font-face);段级排版(对齐/缩进 em·px·%/
边距四向/定宽+margin auto/行距/break-all);盒样式(底色/背景图/四边边框 8 样式/
圆角/阴影/固定高/rotate);简单表格(colspan·rowspan 网格/格内折行/底色边框对齐/
td width 提示/格内图片);行内与块级图片;ruby;float 两档既有降级。

### 边界外(命中即块降级)

| # | 信号 | 现状 | 块渲染后 |
|---|---|---|---|
| S1 | 行内元素盒装饰(span 带 border/background,如圆圈章号 sbox1) | 提取即丢 | 保真 |
| S2 | 嵌套表格 / 超 500 格表格 | 占位文本 | 保真 |
| S3 | 内嵌 `<svg>` 标签(非 svg 文件) | 整段跳过 | 保真 |
| S4 | position:absolute/fixed、flex/grid 布局块 | 属性忽略布局塌 | 保真 |
| S5 | 渐变背景(linear-gradient 等) | 忽略 | 保真 |
| S6 | ::before/::after 生成内容 | 无法支持 | 附带保真(不独立判定:提取器解析不了伪类;S1~S5 命中的块整块渲染天然带上伪类效果) |

## 4. 块级判定(提取期,一次遍历)

- 位置:`HtmlTextExtractor.walkElement` 对每个块级元素先跑 `needsWebViewBlock(node, props)`;
  命中则该元素子树不走常规提取,产出新段落类型 `ParaKind.WEBVIEW`;
- 携带数据:
  - 块 HTML 片段(jsoup 序列化);
  - **祖先壳**:该元素到 body 的祖先链 `cloneNode(false)` 的 class/style 序列
    (渲染时重建 CSS 上下文,保证 `.set-box1 p` 等依赖祖先的选择器与继承语义);
  - 块内纯文本投影(见 §7 对齐规则,保持全书偏移轴连续,目录/TTS/搜索不跳过内容);
- 投影文本是位图语义的近似:选择高亮由 §7 几何表补齐,图片段级别的损失不再存在;
- 整章装饰快照判定(首段带盒样式)**优先且不变**;章内块判定只在非装饰章跑,两者不重叠。

## 5. 块渲染服务(复用装饰章快照基建)

- 离屏 WebView + DECOR_HOST 拦截器(CSS/字体/图片映射)整套复用,粒度从整章改片段;
- mini HTML 组装:原文档 `<head>` 样式链接(相对路径按解压根改写)+ 祖先壳逐层嵌套 +
  块 HTML;注入 `html{font-size: 根字号}` 使块随阅读字号整体缩放;
- 视口宽 = 版心宽;渲染稳定(fonts.ready,4s 硬超时兜底)后 JS 量内容高 → 截图落盘
  `cache/reader/epub/<bookId>/wblocks/<hash>.webp` + 宽高元数据 + 字符几何表(§7);
- 块高超过一页 → 整块等比缩到一页内(与图片行超高同策略);
- **按需生成 + 缓存**:排版遇 WEBVIEW 段先查缓存,未命中才渲染(沿用装饰章
  "阻塞等待补齐"成熟模式);失效条件与整章快照一致:字号、版式指纹、渲染器版本,
  失效时 WebP 与几何表一并重生成;
- 兜底:渲染失败/超时 → 退回纯文本投影自绘绘制,绝不阻塞打开书。

## 6. 排版与绘制集成

- `ChapterLines`:WEBVIEW 段投影**放完整文本**(非 U+FFFC 单字符),复用表格段的
  overrides 行区间机制挂到行模型;绘制层对这些行只画位图、不画文字;
- 行高 = 位图高网格化(按版心宽等比),随段级对齐/左右缩进;
- `DrawLine` 扩展 `blockRef`,绘制层 `drawBitmapFit` 画位图,夜间走现有 ColorMatrix 滤镜;
- TTS 可读块内容、搜索可命中(投影全文本的直接收益)。

## 7. 位图块的长按选择(字符几何映射)

位图上的文字无法被 Canvas 选择体系直接命中,选择几何随快照一并物化:

- **几何表采集**:渲染稳定后 WebView 内执行 JS 遍历文本节点,逐字符
  `Range.getClientRects()` 采集相对块左上角的矩形,产出
  `{字符序列, 每字符[x,y,w,h], 内容宽高}`,与 WebP 同 hash 落盘、同失效条件;
- **投影对齐规则(正确性关键)**:块投影文本与几何表字符序列逐字符一致——两侧共用
  同一条扁平化规则(文本节点原样;块级子元素边界与 `<br>` 折空格;连续空白压一),
  Kotlin 与采集 JS 各实现一遍,**单测对拍钉死**;字符索引 = 投影偏移增量恒成立,
  UTF-16 两侧同构;
- **交互全链复用现有选择体系**:
  1. 长按触点落在块位图矩形内 → 按位图缩放比换算块内坐标 → 几何表最近字符 →
     全书偏移(块投影起点 + 字符索引)→ 进入现有选择状态机;
  2. 拖动扩展:触点持续换算,高亮 = 几何表字符区间矩形并集,画在位图上层 Canvas
     (与自绘选择高亮同绘制路径);
  3. 复制/分享/菜单:按全书偏移取文本的现有管线原样工作,零改动;
- `SelectionGeometry` 扩展"块段委托":块段字符几何来自几何表而非行模型;
- 实现风险兜底:若委托集成受阻,块选择退化为"长按弹块全文弹层"(复用脚注弹层),
  投影轴策略不变。

## 8. 图片点击查看大图

**范围**:

| 对象 | 支持 | 说明 |
|---|---|---|
| 块级图片段(插图/彩页等整图) | ✅ 首批 | 主要场景 |
| 行内图片(角标图/文中小图) | ✅ | 按绘制矩形命中 |
| 表格格内图片(1.5.7 cell 图) | ✅ | drawTable 已有 CellImg 布局坐标 |
| 装饰章快照 / WEBVIEW 块位图 | ❌ | 不响应点击 |
| 封面页 | ❌ | 本身已是整页原图展示 |

- **命中链路**(复用现有 tap 体系,与脚注角标命中同构):tap 无位移手势 → 命中检测
  优先级:块级图片行矩形 → 行内图片矩形 → 格内图片矩形 → 命中则不呼菜单直接预览;
  未命中走现有 tap 逻辑;
- **预览层**(Compose 新组件,挂 ReaderScreen 叠加层体系):全屏近黑半透明底 +
  图片 fit 屏幕居中;双指捏合缩放(1x~4x)、放大后拖动平移、双击 1x/2x 切换、
  单击空白或返回键关闭;
- **加载**:按屏幕尺寸 inSampleSize 采样解码(SVG 走 SvgDecoder 按屏幕尺寸栅格化),
  协程加载 + loading;GIF 取首帧(与现有图片管线一致);
- 不落盘、无保存/分享(最小范围);预览期间阅读页翻页手势冻结,关闭即恢复;
- 图片矩形内的长按仍走选择逻辑,仅无位移单击触发预览。

## 9. 收编清单(机制落地后立刻消灭的降级点)

1. S2 嵌套表/超 500 格的"[表格内容,建议使用原版式查看]"占位 → 块渲染;
2. S3 内嵌 SVG 跳过 → 块渲染;
3. **章首标题装饰表格**(果青1 Section003 场景,S1 自动命中,已拍板纳入,见 §12):
   **不剥除**,表格完整保留 → 块位图呈现;该章隐藏合成章名行
   (hideTitleRow 零占位;页眉仍显示章名,投影轴不受影响);
   同时解决双标题与装饰保真的矛盾。

## 12. 已拍板决策(2026-10)

1. **章首标题装饰表格纳入本期**:机制上线后 S1 信号自动命中该形态(sbox1 行内边框),
   无需专门定制;**不剥除**——`dedupeLeadingTitle` 表格分支的 `drop(1)` 移除,
   表格完整保留并以块位图呈现(双标题由章名行策略解决,大段空白由块渲染精确行高解决);
   该章**合成章名行隐藏**(hideTitleRow 零占位,页眉仍显示章名,投影轴不受影响);
2. **字号变更重渲策略**:块位图跟随阅读字号整体缩放重渲,与整章快照失效策略一致
   (字号、版式指纹、渲染器版本三元组失效,WebP 与几何表一并重生成)。

## 14. 几何采集修复记录(2026-10,渲染器 v2→v9)

首版几何表在真书(果青1,22 块)上 22/22 与位图错位(选择偏移一行、高亮悬空)。
逐层定位到的机制与修复:

- **fonts.ready 早熟**:`document.fonts.ready` resolve 时惰性启动的 @font-face 未必已应用;
  修复 = 采集前对全部声明字体显式 `FontFace.load()`(v3);
- **CSS background-image 不被 load 事件等待**:装饰页插图/底纹常为背景图,迟到重排;
  修复 = 扫全部元素与伪类的 computed backgroundImage 并 `new Image()` 等解码(v5);
- **离屏 WebView 帧产出节流**:draw 可能画到空白帧(白板);修复 = 白板重试绘制
  (250ms×3,v8);
- **布局落地推迟到绘制时刻**:JS 侧提前量到的常是旧布局,且离屏下两遍采集仍可能
  同为旧布局——修复 = 几何改为 **draw 之后的页内终采**(evaluateJavascript),
  收割与位图同源(v7);
- **cropBottomBlank 别名回收**:无裁剪时原样返回入参位图,被 recycle 后压缩必失败,
  runCatching 吞掉后静默丢盘(22 块只落 13);修复 = 别名时不重复回收(v9);
- **正确性兜底 = 像素抽检门**:落盘前抽前 4 个非空格字符矩形,区域内无明暗跨度
  (字形墨迹)即弃用几何写 `{"ok":0}`——显示永远正确,选择宁缺毋错(v7);
  越界矩形不计入有效采样(横向溢出块视口外字符本就不可见,v9);
- **WebView 必须主线程销毁**:IO 协程 `view.destroy()` 直接崩(v8 修)。

v9 实测(果青1):22 块全部落盘;13 块几何像素级贴字形(8 章首装饰表 + 5 名片表,
长按选择可用);9 块(彩色开篇变体,离屏布局在双稳态间轮转)被像素门安全退化
——显示正确、选择不可用,后续可按 §7 风险对策补"长按弹块全文弹层"兜底。
另:书内两个子集字体(parper.ttf/set4.ttf)vmtx 表损坏,被 Chromium OTS 拒载
(桌面 Chrome 同样拒绝,回退渲染一致,非应用侧缺陷)。诊断时序日志经
WebChromeClient 入 logcat(tag `BlkJS`/`BlkRender`,debug 级,发布前可除)。
