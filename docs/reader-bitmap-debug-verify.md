# 位图调试面板验证注意事项（模拟器）

> 2026-10-08 首次验证 v1.5.29 debug 包（位图调试面板功能）过程中沉淀的操作要点。

## 主页 → 阅读入口

- 主页九宫格图标无独立文本节点，`阅读` 标签 bounds 是文字本身（图标在标签上方），
  点击要用整个格子的中心：格子行 bounds 如 `[720,1670][1080,1912]` → tap (900,1791)。
  只按标签 y 附近点会误触上一行（蓝牙应用），且蓝牙页是独立 Activity，返回一次才回主页。
- 书架卡片按标题文本 bounds 中心点击即可（果青1 有多条同名条目，取目标行的那条）。

## 阅读页

- 首次打开大书（果青1 11MB）"解析章节中…"约 4~5 分钟（首渲装饰块，logcat 看
  `BlkJS`/`BlkRender` 在持续输出即未卡死）；期间 uiautomator dump 可能失败，轮询截图
  文件大小（>100KB 一般已出内容）比 dump 更可靠。
- 阅读页**单击任意正文位置都会切换菜单浮层**：想"点右侧翻页"必须先确认菜单已收起，
  否则那一击只是把菜单又打开。翻页用左→右 swipe 更稳（单击边沿容易和菜单开关混淆）。
- 页码 `N/510` 在页脚文本节点，可用 uiautomator dump grep 验证翻页是否生效。

## 位图调试面板（新功能）

- 入口：菜单底栏"设置"左侧网格图标（content-desc `位图调试`），非 EPUB 书时禁用。
- 面板显示当前渲染键命中的块位图：缩略图 + 章/键前缀/尺寸/大小/内存或磁盘/几何状态，
  顶部汇总"块 N · 已渲染 M · 未渲染 K"，过滤框支持章号或键前缀。
- 点列表项弹大图对话框，"关闭"按钮 bounds 以 dump 为准（预览弹窗上 taps 别按截图坐标换算盲点）。
- 对照磁盘：`/data/data/com.yukino.tool.pub.debug/cache/reader/epub/<uuid>/wblocks/*.png`
  数量应等于"已渲染"数（仅辅助定位，不作为功能验证依据）。
